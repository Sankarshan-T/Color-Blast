# Color Blast!
The easiest way to grab colors from the web. Ever see a color on a website—like a beautiful sunset in a photo or a cool neon green on a button—and wish you could use it yourself? This is a simple tool for your Chrome browser that lets you "steal" any color you see and save it for later.

## What can you do with it?
- Pick any color: Just click on the extension and hover your mouse over any part of a website. It will tell you exactly what color you're looking at.

- Save your favorites: You can save colors into a "Palette" so you don't forget them.

- Get the HEX code: Color Blast! gives you the HEX code of any color instantly so you can paste it into Word, Canva, or any design app.
